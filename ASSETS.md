# Asset provenance

`icons/demo.png`, `icons/demo.icns`, the small application/tray marks, `public/wallpapers/` and `public/cursors/default/` plus `src/assets/cursors/` are original geometric drawings generated by `scripts/generate-demo-assets.py`, MIT 2026 Ghostzy0. No proprietary screenshots or private reference images are inputs. Optional regeneration needs Pillow; generated files are committed so normal builds do not need Python.

Six custom cursor packs retained from OpenScreen are explicitly described as original artwork in upstream `src/lib/cursor/cursorThemes.ts`. They use its MIT notice. The default cursor set and wallpaper files had no affirmative provenance evidence and were replaced. Kenney UI Audio click samples have CC0 provenance in THIRD-PARTY-NOTICES.md. Geist and the caption/annotation fonts carry OFL texts; segmentation weights and derived ONNX file have their own Apache provenance and notes. No reserved Pip animation code is included.

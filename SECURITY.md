# Security

Please use GitHub private vulnerability reporting for this repository if it is enabled. Otherwise open an issue without secrets and request a private reporting route. No response SLA is promised.

Do not post recordings, credentials, local paths containing private information, project contents or account data publicly. Supply a synthetic reproduction, OS/architecture, app/source version and expected/observed behavior. These experimental builds are unsigned/ad-hoc and not notarised. Cloud services and remote automation are disabled in the local edition, but native media decoders and broad file access remain a meaningful trust boundary.
